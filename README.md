# 凱撒衛浴選品試算工具 MVP v16

## 本版重點
新增兩個現場規格邏輯：

1. 馬桶糞管距離
2. 沐浴龍頭搭配滑桿 / 蓮蓬頭

## 馬桶糞管距離
前台新增：
- 不確定，先保留可用方案
- 30cm
- 40cm

邏輯：
- 選 40cm 時，不推薦明顯只有 30cm 的智慧馬桶，例如 CA1383。
- 有 40cm 版本或型號含 14 系列者可保留。
- 不確定時，保留候選，但結果備註提醒需現場確認管距。

## 電腦馬桶蓋
保留 v15 邏輯：
- 需要電腦馬桶蓋時，動態組合「一般馬桶 + 溫水洗淨便座」。
- 也保留智慧馬桶與預建馬桶組合。
- 優先一般馬桶 + 溫水洗淨便座，不過濾掉合理智慧馬桶。

## 沐浴龍頭 + 滑桿
前台新增：
- 沐浴龍頭搭配滑桿 / 蓮蓬頭

邏輯：
- 未勾選：只推沐浴龍頭。
- 已勾選：動態建立「沐浴龍頭 + WG滑桿」方案。
- 型號本身已含滑桿的組合，例如 TS620 - WG121，會直接作為含滑桿方案。

## 保留
- 只有按「產生選品」才更新右側。
- 數量 stepper 無上限。
- 預算匹配邏輯。
