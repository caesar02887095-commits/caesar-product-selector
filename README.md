# 凱撒衛浴選品試算工具 MVP v8

## 本版重點
修正 v7 預算邏輯太保守的問題。

## 新邏輯
有填預算時，系統會做「多品項組合試算」：

1. 每個需求先找出可用候選品項。
2. 每個需求必須選一個品項。
3. 系統會嘗試不同品項組合。
4. 目標是：折後總價不超過預算，並且最接近預算。
5. 若所有最低組合仍超過預算，才顯示最低可用組合。

## 與 v7 差異
v7 只會在判斷「明顯更好」時升級，所以預算剩很多也可能不動。
v8 直接以「接近預算」為第一目標，因此會更像真正的預算選品工具。

## 畫面提示
- 【預算匹配】：由預算組合試算選出的品項
- 【最低可用】：最低可用組合仍超過預算時顯示
