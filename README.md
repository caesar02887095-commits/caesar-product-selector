# 凱撒衛浴選品試算工具 MVP v26

## 本版修正
使用者要求不要一直更改前端檔名，避免 GitHub 覆寫困難。

## 檔案規則
從本版開始，zip 內只保留固定檔名：

- index.html
- style.css
- app.js
- README.md

不再產生：

- style-v版本.css
- app-v版本.js

## 快取處理方式
快取改由 index.html 的 query string 處理：

- style.css?v=202607301014
- app.js?v=202607301014

這樣每次更新時，只要覆蓋固定四個檔案即可。

## 保留 v25 功能
- 頁面載入時強制重設折數為 45。
- 頁面載入時強制重設所有品項數量為 0。
- 額外勾選預設收合。
- 數量大於 0 才顯示額外勾選。
- 數量回到 0 時收合並取消勾選。
- 左側字體加大。
