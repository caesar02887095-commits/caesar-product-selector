# 凱撒衛浴選品試算工具 v41-hotfix-cf1354-bidet-empty

## 本版修正
修正選擇 CF1354 / CF1454 這類不建議搭配電腦馬桶蓋的短版馬桶後，右側結果區可能整段崩潰或全部變成缺資料的問題。

## 問題原因
v40 已能判斷 CF1354 / CF1454 不適裝溫水洗淨便座，但在預算模式下，若任一需求群組沒有候選品，原本的 selectBudgetAwareItems 會把全部需求都回傳 missing。

因此使用者選到 CF1354 後，電腦馬桶蓋候選清單為空，整個結果區會看起來壞掉。

## 本版處理
- 保留 CF1354 / CF1454 不建議搭配電腦馬桶蓋的判斷。
- 預算模式下，只有「電腦馬桶蓋」那張卡顯示不適裝提示。
- 馬桶本體卡片保留，不會整組消失。
- 缺資料卡片會顯示明確原因。
