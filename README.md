# 凱撒衛浴選品試算工具 MVP v21

## 本版修正
重新調整左側品項數量區。

## 目標版型
每個品項是一個群組：

品項數量        - 數量 +
□ 額外勾選
□ 額外勾選

下一個品項再接著：

品項數量        - 數量 +
□ 額外勾選

## 修正內容
- 數量列固定為一個橫排。
- 額外勾選固定放在該品項下方。
- 額外規格，例如馬桶糞管距離，也固定放在該品項下方。
- 防止手機版或窄版面超出外框。
