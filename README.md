# 凱撒衛浴選品試算工具 MVP v17

## 本版重點
馬桶糞管距離改成「資料優先」。

## 試算表新增欄位
PRODUCT_MASTER 新增欄位：

- 糞管距離cm

可填：
- 300
- 400
- 300/400

## 前端邏輯
- 如果產品列有填 `糞管距離cm`，前端優先使用這個欄位判斷。
- 如果沒有填，才使用舊版型號備援判斷。
- 因此像 CF1650 已填 300 後，使用者選 40cm 時不會推薦 CF1650。

## 已知已填
- CF1650：300
- CA1383：300

## 保留
- 需要電腦馬桶蓋：動態組合「一般馬桶 + 溫水洗淨便座」。
- 沐浴龍頭搭配滑桿 / 蓮蓬頭：動態組合。
- 只有按「產生選品」才更新右側。
