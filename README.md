# 凱撒衛浴選品試算工具 MVP v15

## 本版重點
修正「需要電腦馬桶蓋」的核心邏輯。

## 舊邏輯
勾選後只從：
- 智慧馬桶
- 預建馬桶組合

挑選。

問題是預建馬桶組合只有少數幾筆，選擇太少，容易造成推薦不合理。

## 新邏輯
勾選「需要電腦馬桶蓋」後，系統會動態建立候選方案：

1. 一般馬桶 + 溫水洗淨便座
2. 智慧馬桶
3. 既有預建馬桶組合

## 選品傾向
- 優先嘗試「一般馬桶 + 溫水洗淨便座」。
- 也就是降低馬桶本體價格，把預算留給電腦馬桶座。
- 智慧馬桶仍保留，但不會壓過合理的馬桶座組合。
- 預算足夠、且更接近預算時，智慧馬桶仍可能被選到。

## 保留
- 只有按「產生選品」才更新右側。
- 預算匹配邏輯。
- 數量 stepper 無上限。
