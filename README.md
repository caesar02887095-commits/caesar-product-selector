# 凱撒衛浴選品試算工具 MVP v23

## 本版修正
修正左側需求區排版，改成真正的品項群組單欄：

品項數量        - 數量 +
□ 額外勾選
□ 額外勾選

## 功能調整
- 預設折數改為 45。
- 所有品項數量預設改為 0。
- 額外勾選 / 額外規格預設隱藏。
- 該品項數量大於 0 時，才顯示額外勾選。
- 浴櫃、鏡櫃寬度改成用公分輸入。
  - 輸入 60，系統內部自動轉成 600mm 比對。
  - 輸入 600 以上則視為舊式 mm 輸入。
