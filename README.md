# 凱撒衛浴選品試算工具 MVP v4

## 本版新增
- `圖片URL` 空白時，會自動用官網頁面產生縮圖。
- `官網URL` 空白時，仍會依型號自動產生凱撒官網網址。
- 型號包含 `/` 或 `+` 時，會優先取第一個主型號作為官網連結與網頁縮圖來源。
  - 例如 `CA1380S / CA1380` → 使用 `CA1380S`
  - 例如 `EM0150 + EM0020` → 使用 `EM0150`
- 點圖片區仍會進入官網頁面。

## 注意
這版的官網縮圖使用外部網頁縮圖服務：
`https://image.thum.io/`

優點是不用每筆產品手動補 `圖片URL`。
缺點是載入速度可能較慢，且若外部服務異常，圖片會顯示失敗。

長期正式版仍建議把常用產品圖片放在 GitHub repo 的 `images/products/` 資料夾，穩定性會更好。
