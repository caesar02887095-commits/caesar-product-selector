# 凱撒衛浴選品試算工具 MVP v3

## 本版新增
- 預算差額改成正負數字
  - `+NT$` 為綠色，表示預算剩餘
  - `-NT$` 為紅色，表示超出預算
- 展開其他可選型號後，可按「改選此品項」
- 鏡櫃新增組合邏輯：
  - 主鏡櫃可搭配開放櫃
  - 例如 EM0150 + EM0020，可視為 70cm 組合
  - 例如 EM0150 + EM0025，可視為 75cm 組合
- 組合品項會加總定價，並用組合後寬度比對需求寬度

## 圖片說明
圖片仍需在 `PRODUCT_MASTER` 的 `圖片URL` 欄補入公開可讀圖片直連。
官網產品頁網址不是圖片網址，不能直接拿來顯示圖片。
