# 凱撒衛浴選品試算工具 MVP v29

## 本版重點
使用者提供截圖指出 v28 左側排版仍太鬆、checkbox 過大、無用空間太多。

## 本版修正
- checkbox 固定為正常大小 16px，不再被 input 樣式撐大。
- 附屬選項改成緊湊列，不再像大卡片。
- 每個 selection-group 的 padding / margin 縮小。
- stepper 尺寸縮小。
- 浴櫃 / 臉盆組的數量、寬度、刪除按鈕間距縮小。
- 左側整體更像表單，減少空白。
